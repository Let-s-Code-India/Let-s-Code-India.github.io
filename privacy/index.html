Privacy Policy

Last updated: 2026-11-02

This policy describes what happens when you browse the Let-s-Code-India website. The site is a static GitHub Pages site; it does not provide accounts, sign-in, or forms, and it does not ask you to submit personal information.

Browser storage

The site sets no cookies itself. It stores the public repository catalog in sessionStorage under let-s-code-india-repos-v1. This lets the current browser tab session reuse the catalog. Browser session storage is normally cleared when that tab session ends. You can clear it through your browser settings.

Requests made by the site

On a normal visit, the browser requests the static data/repos.json catalog from this site. If that file cannot be used, the site falls back to GitHub's public API at api.github.com. It does not call that API for ordinary successful catalog loads.

When you open a repository's “View Details”, the site loads its README from raw.githubusercontent.com and loads local rendering libraries. README content can also cause your browser to request linked resources, including images from GitHub, github.com, *.githubusercontent.com, or img.shields.io. Those requests occur only when details are opened. The README HTML is sanitized before display.

The site is hosted by GitHub Pages. GitHub may receive and log visit and request information under its own privacy statement. Other linked services have their own policies.

Following an external link causes your browser to contact that destination. If you choose to email us or contact GitHub, your message is handled by the email provider or GitHub, not submitted through this site. This site has no contact form or backend.

Analytics

This site uses Google Analytics 4 to collect aggregate usage information. Its loader waits at least ten seconds after the page load event, then waits for idle time where the browser supports it. Very short visits may not be recorded. This delay keeps the analytics download and execution out of the initial page and interaction window. Browser privacy settings, blockers, or network rules can prevent analytics from loading. Google Analytics may set first-party cookies such as _ga and _ga_*. Google signals and advertising personalization are disabled in the site's configuration. See Google's Privacy Policy and Google's Analytics opt-out browser add-on.

Your choices and questions

You can block cookies and JavaScript, clear session storage, or use a browser privacy control. Blocking JavaScript prevents the repository directory and analytics from running, but the rest of the static pages remain available. We do not sell personal data. For a privacy question, contact an address on the Contact page.

Changes

When this policy changes, the date above will be updated. Please review this page again if you want to check the current description.
