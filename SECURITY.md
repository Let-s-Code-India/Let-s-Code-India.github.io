# Security Policy

Please report suspected vulnerabilities privately using the contact details in
[security.txt](https://let-s-code-india.is-a.dev/.well-known/security.txt). Do
not include exploit details in a public issue until a fix is available.

For projects hosted by the organization, see the
[organization security policy](https://github.com/Let-s-Code-India/.github/blob/main/SECURITY.md)
when applicable.
